# Global Superstore Sales Analysis Dashboard

## 📊 Project Overview
This project involves a comprehensive analysis of the **Global Superstore** dataset using Power BI. The goal was to transform raw sales, customer, and return data into actionable business insights regarding profitability, shipping efficiency, and regional performance.

## 🛠️ Tools Used
* **Power BI Desktop**: Data modeling and visualization.
* **Power Query**: ETL (Extract, Transform, Load) process.
* **DAX**: Calculated measures for Profit Margin, YoY Growth, and Return Rates.
* **Excel/CSV**: Data source.

## 📈 Key Features & Insights
* **Executive Summary**: High-level view of Total Sales ($12.6M), Total Profit ($1.5M), and Quantity Sold.
* **Geospatial Analysis**: A map visualization identifying high-performing markets across LATAM, EU, USCA, and APAC.
* **Category Performance**: Deep dive into Technology, Furniture, and Office Supplies.
* **Shipping & Logistics**: Analysis of Order Priority (Critical, High, Medium, Low) and its impact on shipping costs.
* **Trend Analysis**: Monthly sales patterns from 2012 to 2015.

## 🗂️ Data Model
The data consists of three tables:
1.  **Orders**: Transactional data (Sales, Profit, Shipping, etc.).
2.  **People**: Regional managers/contacts.
3.  **Returns**: Information on returned orders to calculate return rates.

🏁 Project Conclusion: Global Superstore Performance Insights
The analysis of the Global Superstore dataset reveals a robust and growing business with a total sales volume of $12.64M and steady profit growth. The dashboard successfully translates millions of rows of transactional data into strategic insights..
